# Archiwalne paczki źródeł

Historyczny ZIP komponentów z 05.10.2026 wycofano z bieżącej dystrybucji 21.11.2026, ponieważ nie zawierał kompletu not licencyjnych. Aktualne komponenty są rozwijane jako jawne źródła w [components](../../components/).

Oryginał zachowano lokalnie wraz z prywatną kopią o sprawdzonej zgodności SHA256. Nie usunięto lokalnych logów ani załączników. ZIP nadal występuje w dawnych commitach i tagach; usunięcie z bieżącej gałęzi nie oczyszcza historycznych archiwów GitHub.

Nie należy odtwarzać starego ZIP jako pakietu do pobrania, dopóki nie zostaną ustalone prawa i dołączone wymagane licencje. Przed publikacją całej historii pozostaje rozwiązanie tej kwestii oraz starych referencji PR.
