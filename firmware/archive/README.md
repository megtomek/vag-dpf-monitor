# Archiwalne paczki źródeł

Historyczny ZIP komponentów z 05.10.2026 wycofano z bieżącej dystrybucji 21.11.2026, ponieważ nie zawierał kompletu not licencyjnych. Aktualne komponenty są rozwijane jako jawne źródła w [components](../../components/).

Oryginał zachowano lokalnie wraz z prywatną kopią o sprawdzonej zgodności SHA256. Nie usunięto lokalnych logów ani załączników. ZIP występował w commitach i tagach poprzedniego repozytorium. Nowe repozytorium ma odrębną historię bez tej paczki.

Nie należy odtwarzać starego ZIP jako pakietu do pobrania, dopóki nie zostaną ustalone prawa i dołączone wymagane licencje. Poprzednie repozytorium ze starymi referencjami PR usunięto na zlecenie właściciela; nie przeniesiono ich do nowej historii.
