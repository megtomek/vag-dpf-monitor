# Pomoc / Support

Projekt społecznościowy, bez gwarantowanego czasu odpowiedzi. Zgłoszenia PL/EN są mile widziane.

1. Sprawdź [zgodność](README.md#zgodność), [instalację](BUILD_INSTRUCTIONS.md) i [typowe objawy](docs/USER_GUIDE.md#najczęstsze-objawy).
2. Przeszukaj [Issues](https://github.com/megtomek/vag-dpf-monitor/issues), także zamknięte. Otwarty PR nie oznacza funkcji w `main` lub Twoim firmware.
3. Użyj szablonu błędu, zgodności ECU albo propozycji. Zwykłe pytanie możesz zadać jako Issue.

Podaj tag/commit, faktycznie wgrany wariant, rewizję płytki, transceiver i ECU/SW/ODX. Opisz zasilanie, stan silnika/zapłonu, sieć i kroki odtworzenia. Udostępniaj tylko potrzebne, przejrzane fragmenty; bez BIN, sekretów, VIN i lokalizacji. Nie zbieraj danych samodzielnie podczas prowadzenia.

Podatności zgłaszaj według [SECURITY](SECURITY.md).

**English:** Check compatibility and existing issues first. Include the source commit, actual flashed configuration, hardware revision, transceiver, exact ECU/SW/ODX, power source and engine/ignition state. Explain reproduction and expected/actual results. Share only redacted diagnostics; no VINs, credentials or firmware images. No response-time or compatibility guarantee is offered.
