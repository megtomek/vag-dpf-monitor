# Zasady społeczności / Code of conduct

Zasady obowiązują w Issues, PR i innych przestrzeniach projektu.

- Szanuj rozmówców; krytykuj rozwiązania, nie osoby. Bez nękania, gróźb i dyskryminacji.
- Oddzielaj pomiar od przypuszczenia. Nie nazywaj profilu lub alarmu potwierdzonym bez dowodów.
- Nie zachęcaj do ryzykownego zbierania danych podczas jazdy ani nieuprawnionego dostępu do pojazdów.
- Chroń prywatność; nie ujawniaj cudzych VIN, lokalizacji, haseł i danych osobowych.

Naruszenie zgłoś maintainerowi `@megtomek`. Dla wrażliwych szczegółów poproś w neutralnym Issue o prywatny kanał zamiast ujawniać dane. Nie powielaj szkodliwej treści publicznie. Podatności: [SECURITY](SECURITY.md).

Maintainer może poprosić o korektę, usunąć treść, zamknąć dyskusję albo ograniczyć udział, uwzględniając kontekst i wpływ na innych. O ponowne rozpatrzenie można poprosić tym samym kanałem; bez gwarancji czasu reakcji.

**English:** Be respectful, discuss evidence and solutions, avoid harassment/discrimination and protect personal/vehicle data. Report violations to `@megtomek`; request a private channel in a neutral issue when sensitive. Maintainers may request corrections, remove content, close discussions or restrict participation, taking context and impact into account. Reconsideration may be requested through the same channel. These are project-specific rules.
